# Repository guidelines

Проектная документация хранится в каталоге `./docs`.

## Процесс разработки

- Каждая задача, требующая реализации, выполняется в отдельном Git worktree.
- Для каждой задачи реализации необходимо написать как минимум unit-тесты; интеграционные тесты добавляются, когда они нужны для проверки затронутого поведения или взаимодействия компонентов.
- После реализации каждой продуктовой или инженерной задачи, включая задачи по CI, необходимо запустить отдельного Codex-агента для независимого ревью изменений.
- После независимого ревью необходимо устранить найденные замечания до завершения задачи.
- Если ревью пройдено успешно, создается PR в main ветку на Github.
