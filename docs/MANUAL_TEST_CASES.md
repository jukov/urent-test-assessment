# Ручное тестирование приложения

Документ описывает ручную проверку пользовательских сценариев приложения перед сдачей. Он дополняет автоматические тесты и ориентирован на наблюдаемое поведение. Кейсы **P0** проверяют критичное поведение, кейсы **P1** расширяют покрытие; полный регресс включает оба приоритета.

## Подготовка

1. Собрать и установить актуальный APK либо запустить `app` из Android Studio.
2. Для основного прогона использовать устройство с Android 13 или новее и размером экрана около 360 × 800 dp. Для проверки совместимости дополнительно использовать Android 9 (API 28).
3. Убедиться, что на устройстве установлен браузер и доступен интернет.
4. Перед проверкой первого запуска остановить приложение и очистить его данные.
5. Сверять внешний вид основных экранов с макетом Figma, указанным в [`TASK.md`](./TASK.md).

API содержит изменяемые данные. Примеры ниже проверены 5 сентября 2026 года:

| Запрос | Ожидаемые подходящие данные |
| --- | --- |
| `Moscow` | `Moscow, Россия` и другие города с `Moscow` в названии |
| `Pristina` | `Pristina, Косово` |
| `New York City` | город с названием из нескольких слов |
| `N'Djamena` | город со специальным символом в названии |
| `zzzz-no-such-city-987654` | пустой результат |

Если конкретный город исчез из API, следует выбрать другой известный город; проверяемое поведение кейса от этого не меняется.

Во время прогона удобно фиксировать результат как `PASS`, `FAIL` или `BLOCKED`. Для дефекта записываются версия APK, модель устройства, версия Android, язык, шаг, фактический результат, скриншот или видео и релевантный фрагмент logcat.

## Быстрый smoke-прогон

Перед каждым релизом выполнить кейсы `MT-01`, `MT-03`, `MT-05`, `MT-06`, `MT-11`, `MT-14`, `MT-17`, `MT-19`, `MT-21`, `MT-24`, `MT-26`, `MT-29`, `MT-31`, `MT-35` и `MT-37`. Этот набор проверяет запуск, основной путь списка, карточку города, браузер, карту, навигацию, восстановление после сетевой ошибки и соответствие макету.

## Запуск и соединение

### MT-01 — Первый запуск с интернетом — P0

**Предусловия:** данные приложения очищены, интернет включён и подтверждён системой.

**Шаги:**

1. Запустить приложение.
2. Дождаться завершения загрузки.

**Ожидаемый результат:** до проверки сети виден нейтральный фон без списка и запросов фич; затем открывается вкладка «Список городов», ненадолго появляется skeleton и отображаются города. Приложение не запрашивает доступ к геолокации.

### MT-02 — Первый запуск без интернета — P0

**Предусловия:** приложение остановлено, Wi-Fi и мобильные данные выключены.

**Шаги:** запустить приложение.

**Ожидаемый результат:** показан экран «Нет подключения к интернету» с пояснением и кнопкой «Попробовать снова». Список, карта и системный запрос геолокации не появляются; приложение не завершается с ошибкой.

### MT-03 — Восстановление соединения на стартовом экране — P0

**Предусловия:** открыт экран отсутствия интернета из `MT-02`.

**Шаги:**

1. Включить интернет и дождаться системного подтверждения подключения, не нажимая кнопку.
2. Убедиться, что приложение само не перешло к списку.
3. Нажать «Попробовать снова».

**Ожидаемый результат:** до нажатия приложение остаётся на стартовом экране. Во время повторной проверки кнопка отключена и показывает «Проверяем соединение…». После успешной проверки открывается список и загружаются города.

### MT-04 — Неуспешная повторная проверка соединения — P1

**Предусловия:** открыт экран отсутствия интернета, соединение всё ещё выключено.

**Шаги:** нажать «Попробовать снова» несколько раз, каждый раз дожидаясь завершения проверки.

**Ожидаемый результат:** после каждой проверки снова доступен тот же экран с активной кнопкой. Дублирующиеся экраны не накладываются, приложение не зависает и не падает.

## Список городов и поиск

### MT-05 — Загрузка и содержимое списка — P0

**Шаги:** открыть вкладку списка с работающим интернетом и прокрутить несколько строк.

**Ожидаемый результат:** каждая строка содержит иконку и текст вида «Название, Страна»; код страны преобразован в локализованное название. Строки не перекрываются, длинные названия занимают не более двух строк, заголовок и поисковое поле остаются сверху. После начала прокрутки у шапки появляется тень.

### MT-06 — Поиск во время ввода и debounce — P0

**Шаги:**

1. В debug-сборке открыть Network Inspector Android Studio или вывод logcat по тегу `Ktor`.
2. Быстро, без пауз больше 300 мс, ввести `Mos`, затем сразу допечатать `Moscow`.
3. Убедиться, что текст появляется в поле без задержки.
4. Подождать не менее секунды и проверить отправленные запросы.

**Ожидаемый результат:** текст поля обновляется при каждом вводе. Поиск начинается только после короткой паузы; промежуточные `M`, `Mo` и `Mos` не создают отдельные запросы. Показаны только результаты для `Moscow`, дублирующихся городов нет.

### MT-07 — Устаревший ответ поиска не заменяет актуальный — P1

**Предусловия:** сетевой proxy или debug fake управляемо задерживает ответ `query=Mos` до получения ответа `query=Moscow`; запросы видны в Network Inspector или logcat.

**Шаги:**

1. Ввести `Mos` и подождать больше 300 мс, чтобы запрос ушёл.
2. До получения ответа допечатать `Moscow` и снова подождать отправки запроса.
3. Сначала вернуть успешный ответ для `Moscow`, затем задержанный ответ для `Mos`.

**Ожидаемый результат:** после ответа `Moscow` показаны соответствующие результаты. Более поздний ответ устаревшего запроса `Mos` не меняет поле, список или состояние загрузки.

### MT-08 — Нормализация поискового запроса — P1

**Шаги:** ввести `  Moscow  ` с пробелами по краям и дождаться результата.

**Ожидаемый результат:** пробелы остаются видимыми в поле, но результат совпадает с поиском `Moscow`; лишний сетевой результат не меняет содержимое списка.

### MT-09 — Пустой результат поиска — P0

**Шаги:** ввести `zzzz-no-such-city-987654` и дождаться загрузки.

**Ожидаемый результат:** старый список заменён сообщением «Города не найдены». Экран не показывает бесконечную загрузку и не предлагает retry, если сервер успешно вернул пустой ответ.

### MT-10 — Возврат к полному списку — P1

**Предусловия:** показан результат любого непустого поискового запроса.

**Шаги:** полностью удалить текст из поля поиска и дождаться загрузки.

**Ожидаемый результат:** загружается первая страница полного списка. Результаты предыдущего поиска не остаются на экране.

### MT-11 — Пагинация — P0

**Шаги:**

1. Открыть полный список без поискового запроса.
2. Медленно прокручивать его вниз.
3. В момент приближения к концу первой порции наблюдать нижнюю часть списка.
4. Продолжить прокрутку после загрузки.

**Ожидаемый результат:** возле конца появляется один индикатор догрузки, затем к списку добавляется следующая страница. Интерфейс остаётся отзывчивым, уже загруженные строки не исчезают, порядок стабилен, повторяющихся строк с одним и тем же городом нет.

### MT-12 — Возврат списка к началу через шапку — P1

**Шаги:** прокрутить список минимум на один экран вниз и нажать на свободную область шапки вне поля ввода.

**Ожидаемый результат:** список возвращается к первой строке. Нажатие на поле поиска продолжает устанавливать курсор и не воспринимается как команда прокрутки.

### MT-13 — Успешное обновление жестом — P1

**Предусловия:** на экране есть список городов, интернет включён.

**Шаги:** потянуть список вниз от его начала и отпустить после появления индикатора.

**Ожидаемый результат:** старые строки остаются видимыми во время запроса, индикатор завершается, первая страница заменяет предыдущие данные без дубликатов. Поисковый запрос в поле сохраняется и применяется к обновлению.

## Карточка города и внешний браузер

### MT-14 — Открытие карточки из списка — P0

**Шаги:** найти `Moscow`, нажать строку `Moscow, Россия`.

**Ожидаемый результат:** плавно открывается экран «Информация о городе». На нём указаны город `Moscow`, страна `Россия`, население с разделителями разрядов и суффиксом «чел», кнопка поиска и кнопка «Назад». Значения соответствуют выбранной строке, экран не зависит от последующей загрузки списка.

### MT-15 — Возврат из карточки — P0

**Предусловия:** город найден через поисковый запрос и открыта его карточка.

**Шаги:** вернуться системным жестом/кнопкой Back; повторить проверку, используя стрелку «Назад» в шапке.

**Ожидаемый результат:** оба способа возвращают на список. Введённый запрос, результаты и позиция списка сохранены; карточка не остаётся поверх вкладок.

### MT-16 — Форматирование Косово — P1

**Шаги:** найти `Pristina` и открыть карточку результата с кодом страны `XK`.

**Ожидаемый результат:** в русском интерфейсе страна показана как `Косово`, в английском — как `Kosovo`; исходный код `XK` пользователю не показывается.

### MT-17 — Поиск информации в браузере — P0

**Шаги:**

1. Найти и открыть карточку `New York City`.
2. Нажать «Поиск информации о городе» и проверить запрос в браузере.
3. Вернуться в приложение, найти `N'Djamena` и повторить поиск информации.

**Ожидаемый результат:** открывается доступный браузер со страницей поиска Google; поисковый запрос равен точному названию выбранного города. Пробелы в `New York City` и апостроф в `N'Djamena` передаются без потери или искажения. После возврата из браузера карточка остаётся открытой.

### MT-18 — Устройство без обработчика браузера — P1

**Предусловия:** тестовый эмулятор не содержит приложения, способного открыть HTTPS-ссылку, либо все такие приложения временно отключены.

**Шаги:** нажать кнопку поиска информации в карточке.

**Ожидаемый результат:** приложение не падает и показывает toast «На устройстве нет доступного браузера».

## Вкладки и сохранение состояния

### MT-19 — Переключение вкладок — P0

**Шаги:** несколько раз переключиться между «Список городов» и «Карта» через нижнюю панель.

**Ожидаемый результат:** выделение активной вкладки меняется сразу, одновременно виден контент только одной вкладки, повторное нажатие активной вкладки не создаёт новый экран. Нижняя панель не перекрывает контент и системную навигацию.

### MT-20 — Сохранение состояния вкладок — P0

**Шаги:**

1. В списке ввести `Moscow` и прокрутить результаты.
2. Перейти на карту, изменить масштаб и положение камеры.
3. Вернуться в список, затем снова на карту.

**Ожидаемый результат:** список сохраняет запрос, результаты и позицию прокрутки; карта возвращается к сохранённой области и масштабу, без скачка к начальному положению Москвы.

## Карта

### MT-21 — Первичная загрузка карты — P0

**Шаги:** открыть вкладку «Карта» с работающим интернетом и дождаться загрузки.

**Ожидаемый результат:** отображается подложка карты с видимой атрибуцией, начальная область находится возле Москвы, поверх карты появляются подписанные маркеры городов. Сообщение «Загружаем города…» исчезает после успешного ответа. Разрешение геолокации не запрашивается.

### MT-22 — Панорамирование и обновление маркеров — P1

**Предусловия:** используется debug-сборка; сетевые запросы видны в logcat по тегу `Ktor` или в Network Inspector Android Studio. Для проверки порядка ответов proxy или debug fake задерживает первый запрос области до завершения второго.

**Шаги:**

1. Быстро перемещать карту несколько секунд, затем остановить её в другой области и проверить отправленные запросы.
2. Для проверки гонки остановить карту в области A и дождаться отправки запроса, не возвращая ответ.
3. Переместить карту в область B, вернуть её ответ, а затем вернуть задержанный ответ области A.

**Ожидаемый результат:** карта двигается плавно; запрос маркеров выполняется после остановки, а не на каждое промежуточное движение. Показаны города последней области B; маркеры старых областей не накапливаются, и поздний ответ области A не возвращает их на карту.

### MT-23 — Масштаб карты — P0

**Шаги:**

1. Нажать `+`, затем `−`.
2. Проверить pinch-to-zoom и двойное нажатие.
3. Попробовать вращение и наклон двумя пальцами.

**Ожидаемый результат:** `+` приближает, `−` отдаляет; обычные жесты масштабирования работают. Вращение и наклон отключены. После завершения масштаба набор маркеров соответствует новой видимой области.

### MT-24 — Выбор маркера — P0

**Шаги:** нажать подписанный маркер города.

**Ожидаемый результат:** выбранный маркер визуально выделяется, снизу раскрывается карточка с названием, локализованной страной, форматированным населением и кнопкой поиска. Камера плавно располагает маркер по центру свободной над карточкой области, не меняя масштаб. Кнопки `+`/`−` остаются доступны и не перекрываются карточкой.

### MT-25 — Повторный выбор и закрытие карточки карты — P1

**Шаги:**

1. С открытой карточкой нажать другой видимый маркер.
2. Закрыть карточку нажатием на её верхнюю ручку.
3. Открыть её снова и закрыть свайпом вниз.
4. Открыть ещё раз и нажать системный Back.

**Ожидаемый результат:** при выборе другого маркера содержимое заменяется данными нового города, выделение переходит на него, камера фокусирует новый маркер. Каждый способ закрытия полностью скрывает карточку и снимает выделение; системный Back сначала закрывает карточку, а не приложение.

### MT-26 — Поиск из карточки карты — P0

**Шаги:** выбрать город на карте и нажать кнопку поиска информации.

**Ожидаемый результат:** браузер открывает поиск точного названия города. После возврата карта, камера, выбранный маркер и карточка сохранены.

### MT-27 — Область без городов — P1

**Шаги:** сильно приблизить карту над участком океана вдали от населённых пунктов и дождаться ответа.

**Ожидаемый результат:** предыдущие маркеры очищаются, карта остаётся доступной, показано сообщение «В этой области нет городов». После перехода к населённой области сообщение исчезает и появляются актуальные маркеры.

## Сетевые ошибки и восстановление

Стартовый экран проверяет наличие валидированного соединения только до входа в приложение. Чтобы проверить ошибки фич, сначала пройти `MT-01`, а затем отключать сеть уже внутри списка или карты. Для ошибки самого первого API-запроса нужно оставить интернет валидированным и управляемо изменить ответ backend.

### MT-28 — Ошибка первоначальной загрузки API и retry — P0

**Предусловия:** устройство использует сетевой proxy или debug fake, который пропускает проверку интернета, но может заблокировать либо заменить первый `GET api/cities` на HTTP 500. Данные приложения очищены.

**Шаги:**

1. Включить правило ошибки только для первого запроса `api/cities` и запустить приложение.
2. Дождаться полноэкранной ошибки списка.
3. Отключить правило, не перезапуская приложение, и нажать «Повторить».
4. Дополнительно повторить сценарий с malformed JSON, если proxy умеет подменять тело ответа.

**Ожидаемый результат:** приложение проходит стартовую проверку сети, затем показывает полноэкранную ошибку «Не удалось загрузить города» с retry. Список не остаётся в бесконечной загрузке и приложение не падает. После восстановления корректного ответа retry загружает первую страницу.

### MT-29 — Ошибка нового поиска и retry — P0

**Предусловия:** основной экран уже открыт.

**Шаги:**

1. Выключить Wi-Fi и мобильные данные.
2. Ввести новый поисковый запрос и дождаться ошибки.
3. Включить интернет.
4. Нажать «Повторить».

**Ожидаемый результат:** вместо стартового offline-экрана появляется ошибка списка «Проверьте подключение к интернету и попробуйте снова». После retry загружаются результаты текущего запроса; перезапуск приложения не требуется.

### MT-30 — Ошибка пагинации и retry — P1

**Предусловия:** первая страница полного списка загружена.

**Шаги:**

1. Прокрутить примерно до середины первой страницы и отключить сеть.
2. Дойти до конца, чтобы началась загрузка следующей страницы.
3. Дождаться ошибки, включить сеть и нажать нижнюю кнопку «Повторить».

**Ожидаемый результат:** ранее загруженные города остаются видимыми, ошибка и retry находятся внизу списка. После retry добавляется следующая страница без очистки, перестановки и дубликатов.

### MT-31 — Ошибка pull-to-refresh и восстановление — P0

**Предусловия:** список с городами загружен.

**Шаги:**

1. Отключить сеть и выполнить pull-to-refresh.
2. Дождаться сообщения об ошибке и убедиться, что список сохранён.
3. Включить сеть и снова выполнить pull-to-refresh.

**Ожидаемый результат:** после первой попытки текущий список остаётся видимым, индикатор завершается и появляется snackbar с понятным сообщением. После восстановления сети обновление успешно завершается и показывает актуальную первую страницу без дубликатов.

### MT-32 — Ошибка карты и retry — P0

**Предусловия:** карта и маркеры успешно загружены.

**Шаги:**

1. Отключить сеть.
2. Передвинуть карту так, чтобы потребовался новый запрос, и дождаться ошибки.
3. Включить сеть и нажать «Повторить».

**Ожидаемый результат:** поверх доступной карты появляется «Не удалось загрузить карту или города», а маркеры последнего успешного ответа не исчезают во время загрузки и ошибки. После retry ошибка пропадает и маркеры заменяются данными текущей области.

## Локализация, конфигурация и доступность

### MT-33 — Русский и английский интерфейс — P1

**Шаги:** на Android 13+ по очереди выбрать русский и английский язык в системной настройке языка приложения; на Android 12 или ниже сменить язык системы и перезапустить приложение.

**Ожидаемый результат:** все заголовки, кнопки, ошибки, вкладки и подписи отображаются на выбранном языке. Названия стран и разделители числа населения соответствуют локали. Непереведённых resource-id, смешения языков и перезапуска в неправильный экран нет.

### MT-34 — Поворот экрана и пересоздание Activity — P1

**Шаги:** по очереди повернуть устройство при открытом поиске, карточке города, изменённой карте и карточке маркера. При наличии возможности включить developer option «Не сохранять действия» и повторить переход в фон и обратно.

**Ожидаемый результат:** приложение не падает; поисковый текст, карточка города, положение камеры и выбранный город восстанавливаются. Повторная загрузка не создаёт дубликаты, bottom sheet не накладывается сам на себя.

### MT-35 — Системные inset, клавиатура и малый экран — P0

**Шаги:**

1. Проверить приложение с жестовой и трёхкнопочной системной навигацией.
2. Открыть клавиатуру в поиске и прокрутить список.
3. На небольшом экране открыть карточку города и карточку маркера.

**Ожидаемый результат:** статус-бар, navigation bar и клавиатура не перекрывают поле, кнопки и нижнюю панель; контент карточек прокручивается, кнопка поиска достижима. После скрытия клавиатуры layout возвращается в нормальное состояние.

### MT-36 — Крупный шрифт и TalkBack — P1

**Шаги:** установить системный размер шрифта 200%, включить TalkBack и пройти список, вкладки, карточку города, карту, zoom-кнопки и закрытие карточки.

**Ожидаемый результат:** критичные тексты и действия доступны без обрезания; фокус идёт в понятном порядке. TalkBack озвучивает вкладки и их выбранное состояние, поиск, «Назад», `+` как «Приблизить», `−` как «Отдалить» и действие закрытия карточки. Декоративные иконки не создают лишние элементы фокуса.

## Визуальная и релизная проверка

### MT-37 — Сверка с Figma — P0

**Шаги:** сделать скриншоты списка, пустого результата, ошибки, карточки города, карты и открытой карточки маркера на размере экрана, близком к макету; сравнить их с соответствующими фреймами Figma.

**Ожидаемый результат:** совпадают структура, отступы, размеры, цвета, типографика, скругления, иконки, состояния кнопок и положение элементов с учётом системных inset. Нет случайной тёмной темы: обязательная светлая тема выглядит целостно. Любое существенное расхождение с макетом считается блокирующим сдачу.

### MT-38 — Подписанный release APK на минимальной версии Android — P1

**Предусловия:** получен подписанный release APK из GitHub Release проекта либо APK подписан тестовым ключом после `assembleRelease`; эмулятор или устройство Android 9 (API 28) не содержит предыдущей установки.

**Шаги:** установить APK, запустить приложение и пройти `MT-01`, `MT-06`, `MT-14`, `MT-17`, `MT-19`, `MT-21` и `MT-24`.

**Ожидаемый результат:** APK устанавливается и запускается; основные сценарии работают так же, как в debug-сборке, без debug-инструментов, crash и отсутствующих ресурсов.

## Критерий завершения прогона

Релиз можно считать прошедшим ручную проверку, если все P0-кейсы имеют статус `PASS`, среди P1 нет дефектов, блокирующих основной сценарий или сдачу задания, а найденные отклонения зафиксированы с достаточными данными для воспроизведения. `BLOCKED` не считается успешным результатом: необходимо устранить причину блокировки или явно согласовать ограничение релиза.
