# Тестовое задание

## Цель

Разработать приложение для просмотра городов в соответствии с предоставленным дизайном и API.

Приложение должно демонстрировать владение следующими технологиями и подходами:

- Kotlin;
- Dependency Injection (DI);
- Coroutines;
- JSON/XML;
- REST API;
- Git;
- SOLID;
- ООП.

## Обязательный стек

- [Jetpack Compose](https://developer.android.com/compose);
- [Orbit MVI](https://github.com/orbit-mvi/orbit-mvi);
- [Ktor](https://github.com/ktorio/ktor).

## Общие требования

- Код должен быть аккуратным и архитектурно соответствовать production-подходу в понимании кандидата.
- Реализация должна строго соответствовать [макету в Figma](https://www.figma.com/design/gJHFDEx7bHwaeMrHoypyYm/%D0%A2%D0%B5%D1%81%D1%82%D0%BE%D0%B2%D0%BE%D0%B5-%D0%B7%D0%B0%D0%B4%D0%B0%D0%BD%D0%B8%D0%B5--Copy-?node-id=20-2653&t=hYzHYrOWA0U01KD7-0).
- Для просмотра параметров вёрстки, шрифтов и цветов в Figma необходимо авторизоваться. В анонимном режиме соответствующая панель может не отображаться.

## Экран городов

Экран должен:

- содержать поле ввода для поиска города;
- отображать список городов с поддержкой пагинации;
- обновлять список в реальном времени по мере ввода текста в поле поиска;
- отображать в превью города поля `name` и `country`.

### API

```http
GET http://dev-dep.tools.urent.tech:8080/api/cities
```

Query-параметры:

| Параметр | Описание |
| --- | --- |
| `query` | Фильтр по названию города |
| `page` | Номер страницы |
| `limit` | Количество элементов на странице |

## Экран информации о городе

Экран должен:

- отображать данные выбранного города: `name`, `country`, `pop`;
- содержать кнопку «Поиск информации о городе»;
- по нажатию на кнопку открывать браузер с поисковым запросом по полю `name` выбранного города.

## Дополнительное задание

Реализовать экран с картой и модальным окном.

### API

```http
GET http://dev-dep.tools.urent.tech:8080/api/cities/map
```

Query-параметры:

| Параметр | Описание |
| --- | --- |
| `centerLat` | Широта центральной координаты экрана |
| `centerLng` | Долгота центральной координаты экрана |
| `radius` | Радиус поиска в метрах |
