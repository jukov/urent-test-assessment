# Шрифт пинов

`roboto-bold-glyphs.zip` содержит подготовленные символы Roboto Bold для MapLibre,
включая латиницу и кириллицу. Архив входит в APK, поэтому шрифт доступен без сети.

Источник — [fonts.pbf, версия 2d1fd48](https://github.com/korywka/fonts.pbf/tree/2d1fd482a5afa0a856277148ee0af3cc6a9db0ff/Roboto%20Bold).
Все 256 диапазонов PBF сохранены без изменений. Они созданы fontnik из Roboto
проекта OpenMapTiles. Исходный шрифт распространяется под Apache License 2.0.
